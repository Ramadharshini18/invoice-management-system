# ByteForce Technology – Invoice Management System

A professional, full-featured Invoice Management System developed by ByteForce Technology for managing ABC Company invoices.

## Quick Start

### Option 1: Double-click `run.bat`

This will automatically install dependencies and start both servers.

### Option 2: Manual Start

```bash
# Terminal 1 - Backend
cd backend
npm install
node server.js

# Terminal 2 - Frontend
cd frontend
npm install
npm run dev
